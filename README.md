# agrinho_2026
🌱 Agro Forte, Futuro Sustentável

Equilíbrio entre produção agrícola e preservação ambiental.
Site educativo que mostra como o agronegócio pode ser produtivo e sustentável ao mesmo tempo.

Funcionalidades
Banner inicial impactante com mensagem central.
Navegação simples e responsiva.
Seções: Sobre, Benefícios e Práticas Sustentáveis.
Cards e listas destacando ações concretas.
Tecnologias
HTML5 e CSS3
Design responsivo
Como usar
Baixe ou clone o repositório.
Abra index.html em qualquer navegador.
